# Portal artwork and dependencies

The vector illustrations in `src/PortalArt.jsx` are original artwork authored for this project. They use inline SVG geometry and do not load external thumbnails or assets from Poki. The seven illustration themes are reused across the catalog; they are representative illustrations, not gameplay screenshots.

Interface icons come from the existing `lucide-react` dependency (ISC license); its installed license is in `node_modules/lucide-react/LICENSE`. Existing Nunito typography is requested by the retained stylesheet from Google Fonts; if unavailable, the interface uses system fonts. Nunito is distributed under the SIL Open Font License.

Existing standalone games and learning activities retain their existing files and licensing obligations. This change does not establish an independent rights audit of all pre-existing content. No proprietary Poki game, logo, thumbnail or game build is included.
